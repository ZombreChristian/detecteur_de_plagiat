# Dataset fictif — Détecteur de plagiat et de doublon d'études

Ce dossier contient des documents synthétiques destinés exclusivement aux tests et à la validation technique du système. Les documents fictifs ne représentent aucune étude réelle de l'administration.

Le dataset doit couvrir :
- la détection de doublons sémantiques entre TDR ;
- la copie littérale entre rapports ;
- la paraphrase ;
- les passages administratifs récurrents pouvant constituer des faux positifs structurels ;
- les documents réellement distincts ;
- la diversité des secteurs, zones géographiques, années et structures.

Chaque document fictif doit être identifiable par son code et associé à des métadonnées permettant d'évaluer objectivement les résultats du moteur.
